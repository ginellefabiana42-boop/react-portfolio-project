# SYS.ONLINE // Personal Portfolio

A responsive, interactive personal portfolio website built with React.js. Designed with a dark, tech-inspired "cybersigilism" aesthetic to showcase projects, skills, and creative commissions.

## Features
- **Modern Tech Stack:** Built with React (Vite) for optimal performance.
- **Client-Side Routing:** Seamless page navigation using `react-router-dom`.
- **Fluid Animations:** Smooth transitions and stagger effects powered by `framer-motion`.
- **Form Validation:** Robust contact form handling using `react-hook-form`.
- **Responsive Design:** CSS Grid and Flexbox ensure a flawless experience across mobile, tablet, and desktop displays.

## Setup Instructions
To run this project locally on your machine:

1. **Clone the repository:**
   \`\`\`bash
   git clone [YOUR_GITHUB_REPO_LINK]
   \`\`\`
2. **Navigate to the project directory:**
   \`\`\`bash
   cd my-portfolio
   \`\`\`
3. **Install dependencies:**
   \`\`\`bash
   npm install
   \`\`\`
4. **Start the development server:**
   \`\`\`bash
   npm run dev
   \`\`\`
5. **Open your browser:**
   Navigate to `http://localhost:5173` to view the live build.
